# DSH Mobile

[English](README.md) | 中文

`@deepseek-ai/dsh-mobile` 是远程 DSH 会话的原生 Expo 客户端基础。它提供以会话为中心的移动工作区、沉浸式对话视图、输入区域和以配对为先的连接流程。

当前 UI 是本地预览。其中的示例会话和消息不会离开设备，输入的草稿也只在预览打开期间存在。在相机支持缺失时，用户可以手动粘贴由桌面端签发的配对代码。共享配对解析器在内存中校验该代码，清除原始值，且绝不记录或持久化其中的中继 token。

该流程区分已解析的本地请求、等待桌面端接受时的阻塞状态，以及仅用于视觉展示的已配对会话壳预览。应用不会发起网络请求、打开中继连接、应用密码学，也不会声称桌面端已接受手机。固定的移动端范围是读取和订阅已有会话、向已有会话发送文本，以及取消 turn。计算机使用、批准、文件、凭据、workspace 与设置变更、附件和创建会话仍仅限桌面端。
