# DSH Mobile

[English](README.md) | 中文

`@deepseek-ai/dsh-mobile` 是远程 DSH 会话的原生 Expo 客户端基础。它提供以会话为中心的移动工作区：离线会话浏览器、沉浸式对话视图、输入区域和配对设置。

当前 UI 是本地预览。其中的示例会话和消息不会离开设备，输入的草稿也只在预览打开期间存在。应用不会发起网络请求，也不会收集或持久化网关地址、二维码、帐户令牌或凭据。

在应用能够加载历史记录、流式接收会话状态或发送经用户批准的消息之前，已认证的移动网关必须将用户与桌面设备配对，并执行服务器端会话和权限策略。计算机使用和 macOS 隐私权限仍仅限桌面端。
