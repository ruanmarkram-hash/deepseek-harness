## Design Context

### Users

Developers and operators use DSH to run, inspect, and continue agent sessions across a Mac desktop and a phone. The desktop owns local execution, approvals, and computer-use permissions; mobile is a secure companion for session continuity.

### Brand Personality

Calm, exact, and capable. The product should feel like a focused working environment, drawing interaction cues from Codex on desktop and ChatGPT's immersive session views on mobile. It is a separate DSH product, not a MyOS surface.

### Aesthetic Direction

Dense but breathable native workspace. Prefer restrained hierarchy, purposeful status signals, full-screen conversation focus, and quick session switching over decorative cards or generic dashboard treatments. Support a dark working context without neon effects, ornamental gradients, or glass surfaces.

### Design Principles

1. Preserve the desktop-only boundary for execution, approvals, and operating-system permissions.
2. Make session state, connection state, and pending user action immediately legible.
3. Keep the conversation as the primary work surface and reveal secondary controls progressively.
4. Use native platform conventions where they improve speed, keyboard use, and accessibility.
5. Never represent preview, cached, or disconnected data as live session state.
