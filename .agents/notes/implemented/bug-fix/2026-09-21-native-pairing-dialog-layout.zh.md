# Agent Note: 原生配对对话框尺寸

Status: implemented

[English](2026-09-21-native-pairing-dialog-layout.md) | 中文

## 问题

用作 NSAlert 附属视图的无约束堆栈可能保留 QR 图像的固有尺寸，即使图像视图的 frame 更小。生成的对话框会裁剪 QR code 和手动文本，使手机无法注册。

## 决定

配对展示使用显式设置尺寸的附属视图。QR 模块采用整数尺寸，并带有四个模块宽的不透明白色静区；完整的可选择手动代码按字符换行。QR 渲染失败时保留手动代码。配对、有效期和指纹批准逻辑保持不变。

## 考虑过的替代方案

**仅缩小图像 frame** 不能确定附属视图的尺寸，仍可能因固有尺寸而发生裁剪。

**截断文本并附带工具提示** 使手动输入依赖鼠标悬停，且对读屏用户隐藏部分凭据。

## 影响

对话框占用更多垂直空间，以显示完整凭据。AppKit 测试对真实 alert 进行布局，验证视图包含关系、手动回退以及 QR 编解码一致性。独立的 fixture（测试前置数据）代码渲染使用同一个展示构建器，不启动 Host，也不访问凭据。这些检查不能替代在实体手机上扫描已发布签名 app。
